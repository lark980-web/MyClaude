# MyClaude ↔ Claude Code 差异报告（2026-10-25）

证据来源：claude-src 字节码字符串提取（位置无语义，描述不可恢复，标注置信度）+ 本仓库实测。
方法：命令/钩子/工具三维扫描 + 关键接线核查。REA 技能规则允许完整源码树用常规工具。

## 一、本次新发现的缺口（此前矩阵未覆盖）

### 1. /effort 是死设置（置信度：高，实测）
config.effort 有存储、有 /status 显示，但**全仓库无任何消费者**——provider 不发送、
无提示词注入。与已修复的 fastMode 完全同病。Claude 的 /effort 是真实命令。
另：GUI「深度思考」按钮走的是另一条路（提示词包装 <think> 标签），与 /effort 无关——
同一个意图有两套互不相通的入口。

### 2. 钩子事件缺 2 个（置信度：高）
claude-src 常量池中的权威序列（顺序即源码数组）：
  Stop, SubagentStop, UserPromptSubmit, SessionStart, SessionEnd,
  PreToolUse, PostToolUse, PreCompact, Notification —— 共 9 个
MyClaude 7 个，缺 SessionStart（会话启动注入上下文）与 SessionEnd（会话结束清理/上报）。
PermissionRequest/PermissionDenied 在字节码中出现 1-3 次，疑似权限流内部字符串而非钩子
事件（未确证，不计入）。

### 3. MCP 资源工具缺 2 个（置信度：高）
Claude 把 ListMcpResources / ReadMcpResource 作为模型工具暴露；MyClaude 的 MCP client
已实现 listResources/readResource 传输层，但没有桥接成模型可用工具。

### 4. Claude 有而 MyClaude 未实现的命令（按可实现性分层）
本地可实现（无云端依赖）：
  /context   上下文明细可视化（MyClaude 的 /status 只有粗略统计）
  /todos     查看 TodoWrite 待办列表（工具有了，命令入口没有）
  /add-dir   追加工作目录（MyClaude 单 cwd）
  /skill     按名调用技能（MyClaude 只有 /skills 列表）
  /agents    子代理定义文件管理（.claude/agents 形态）
  /release-notes 版本说明
终端专用（GUI 产品形态不同，价值有限）：
  /vim /terminal-setup /statusline /output-style /ide（IDE 协议，工程量大）
云端/账号依赖（不可实现，与已知三项同类）：
  /login /logout /upgrade /install-github-app /feedback /bug /usage /desktop

### 5. 命令存在性意外（置信度：中）
/effort /fast /rewind /sandbox 确认为 Claude 真实命令——此前矩阵把前两个当作
MyClaude 自创功能。/sandbox 在 Windows 上 Claude 自身不可用（与已记录的沙箱结论一致）。

## 二、工具对比

MyClaude 23 = Claude 的工具集（TodoWrite/MultiEdit/AskUserQuestion/WebSearch/
NotebookEdit/BashOutput/KillShell/TaskOutput 等全部在）+ 4 个 Git 扩展（GitCommit/
GitDiff/GitLog/GitStatus，Claude 用 Bash git，属 MyClaude 扩展）− 2 个 MCP 资源工具。
SlashCommand / EnterPlanMode 工具在 claude-src 中不存在（计划进入靠命令/快捷键，
MyClaude 用 /mode plan，语义等价）。

## 三、已确认对齐的核心面

- 核心回路：流式工具调用、三阶段并发、权限七模式、diff 审批、命令安全分级、
  auto 审查模型、checkpoint/rewind、会话持久化/恢复/分叉
- 扩展体系：skills 目录制、plugin 组件、hooks 7 事件、MCP 三传输 + OAuth 设备流
- 命令 46 个，覆盖 Claude 本地命令的主要面
- 50 项功能矩阵全部有测试或实跑验证（replica/features.csv）

## 四、结论

结构面已对齐；剩余差异分三类：
1. 接线缺口（/effort 死设置、MCP 资源工具、SessionStart/End 钩子）—— 小改动
2. 命令补齐（/context /todos /add-dir /skill /release-notes /agents）—— 中等改动
3. 不可复制（云端命令、多智能体协作、Windows 沙箱、IDE 集成）—— 已记录原因
