# myclaude

An original terminal coding agent with tool use, plus a Claude-style web GUI

> Generated by `/init`. Edit freely — the agent reads this on every start,
> and it is sent as part of the system prompt.

## Entry points

- `src/main.js`

## Layout

- `bin/`
- `docs/`
- `scripts/`
- `src/`
- `vendor/`

## Commands

- `npm run dev` — node bin/myclaude.js --gui --port 3000 --no-open
- `npm run start` — node bin/myclaude.js --gui --port 3000 --no-open
- `npm run build:embed` — node scripts/bundle-gui.mjs
- `npm run build` — node scripts/bundle-gui.mjs
- `npm run gui` — node bin/myclaude.js --gui
- `npm run test` — node --test "test/*.test.js"
- `npm run build:exe` — node scripts/build-exe.mjs
